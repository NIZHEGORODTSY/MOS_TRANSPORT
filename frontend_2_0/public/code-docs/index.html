МосТранспорт — предиктор изменений в графике движения¶

Система в реальном времени принимает телеметрию NDTP, накладывает её на плановое расписание и за 10–15 минут до прибытия на остановку прогнозирует задержку каждого ТС. Диспетчер видит на карте, кто опаздывает, кто в зоне риска и кто идёт по графику.

Это документация по коду (Sphinx, autodoc по docstring-ам) и описание устройства системы. Спецификация API — в Swagger бэкенда (/docs на сайте) и в файлах openapi.json (бэкенд) и ml_openapi.json (ML-сервис).
