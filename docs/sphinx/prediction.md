# Цикл прогноза

Цикл работает в бэкенде ({func}`app.main.run_predictions`) раз в `ML_PREDICT_S` секунд (по умолчанию 30).

## Шаги

1. **Точки прогноза** — {func}`app.predictor.make_points`. Для каждого ТС, которое на связи,
   имеет плановое расписание и не меньше 15 минут истории:
   * момент прогноза **T** — время последнего пакета ТС (время потока, а не часы сервера);
   * **целевая остановка** — первая по плану с прибытием в `(T+10 мин, T+15 мин]`
     ({meth}`app.predictor.Schedule.target`); если такой нет (отстой, конец смены), прогноз не строится;
   * `cur_dev_s = 0`: подсказки организаторов «текущее отклонение» в потоке NDTP нет.
2. **Контекст** — {func}`app.predictor.set_context`: история всех ТС за час
   ({meth}`app.telemetry.TelemetryStore.history_rows`) и плановое расписание уходят на `/set_context`
   ML-сервиса. Фактические времена прибытия в ML-сервис не передаются.
3. **Прогноз** — {func}`app.predictor.predict`: все точки одним запросом `/predict`.
4. **Результат** сохраняется в `TelemetryStore.predictions` и в ряд прогнозов ТС за час;
   дашборд получает его вместе с состоянием ТС по WebSocket.

Запросы к ML выполняются в отдельном потоке (`asyncio.to_thread`), поэтому цикл не блокирует API
и рассылку. Время цикла — `status.elapsed_s` в `GET /api/predictions`.

## Уровень риска

{func}`app.predictor.risk_level` по прогнозу задержки на целевой остановке:

| `risk` | Статус на карте | Прогноз задержки |
|---|---|---|
| `late` | опаздывает (красный) | больше +3 мин |
| `risk` | риск опоздания (жёлтый) | от +1 до +3 мин |
| `on_time` | успевает (зелёный) | в пределах ±1 мин |
| `early` | раньше графика (белый) | раньше больше чем на 1 мин |

## Состояния цикла

`status.state` в `GET /api/predictions`:

| Состояние | Значение |
|---|---|
| `starting` | бэкенд только запустился |
| `warming_up` | ни у одного ТС ещё нет 15 минут истории или целевой остановки |
| `ok` | прогноз посчитан |
| `error` | ML-сервис недоступен или вернул ошибку; последние прогнозы сохраняются |
| `disabled` | не загрузилось расписание |
